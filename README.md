# Projeto-Site-Android  
*Uma breve jornada pela história do sistema Android*

## 🎯 Visão geral  
Este projeto visa apresentar a evolução do sistema operacional Android — desde seus primórdios até os dias atuais — por meio de um site estático desenvolvido com HTML e CSS.  
Ele serve tanto como material educativo quanto como demonstração das minhas habilidades em front-end, organização de conteúdo e boas práticas de estrutura de projeto.

## ✅ Funcionalidades principais  
- Página inicial com introdução e cronologia da evolução do Android.  
- Seções dedicadas aos marcos históricos: lançamentos, versões, inovações tecnológicas.  
- Layout responsivo (ou se for, especifique; se não, mencione “pronto para responsividade”).  
- Uso de pastas organizadas para estilos (`/estilo`), fontes (`/fontes`) e imagens (`/imagens`) — demonstrando atenção à estrutura e manutenibilidade.

## 🛠 Tecnologias utilizadas  
- HTML5  
- CSS3  
- Estrutura de diretórios organizada (`estilo/`, `fontes/`, `imagens/`)
